# Project Planning

Giai đoạn lập kế hoạch dự án (Planning Process Group) - nơi chuyển các tài liệu khởi động đã được phê duyệt thành kế hoạch thực thi chi tiết về phạm vi, tiến độ, nguồn lực, chi phí, chất lượng, rủi ro và truyền thông.

## Tài liệu

| Tài liệu | Mô tả |
| --- | --- |
| [WBS](./wbs.md) | Cấu trúc phân rã công việc và các gói công việc chính |
| [Roadmap](./roadmap.md) | Lộ trình triển khai tổng thể theo giai đoạn |
| [Milestone](./milestone.md) | Danh sách mốc quan trọng và tiêu chí hoàn tất |
| [Sprint Plan](./sprint-plan.md) | Kế hoạch sprint, mục tiêu sprint và backlog cấp cao |
| [Release Plan](./release-plan.md) | Kế hoạch phát hành MVP, beta, UAT và production |
| [Resource Plan](./resource-plan.md) | Kế hoạch nhân sự, vai trò và phân bổ nguồn lực |
| [Capacity Planning](./capacity-planning.md) | Ước tính năng lực đội ngũ và tải công việc theo sprint |
| [Risk Plan](./risk-plan.md) | Kế hoạch quản lý rủi ro, phản ứng rủi ro và owner |
| [Communication Plan](./communication-plan.md) | Kế hoạch truyền thông chi tiết theo stakeholder và kênh |
| [Quality Plan](./quality-plan.md) | Tiêu chuẩn chất lượng, quality gates và quy trình kiểm soát |
| [Test Strategy](./test-strategy.md) | Chiến lược kiểm thử chức năng, hiệu năng, bảo mật và UAT |
| [Dependency Map](./dependency-map.md) | Bản đồ phụ thuộc giữa team, vendor, API, hạ tầng và deliverables |
| [Cost Estimation](./cost-estimation.md) | Ước tính chi phí theo hạng mục, nguồn lực và công nghệ |
| [Budget](./budget.md) | Ngân sách phê duyệt, dự phòng và cơ chế kiểm soát chi phí |
| [Schedule](./schedule.md) | Lịch trình tổng thể, baseline tiến độ và quan hệ phụ thuộc |

## Quy trình chính

- **Plan Scope Management** - Lập kế hoạch quản lý phạm vi
- **Create WBS** - Tạo cấu trúc phân rã công việc
- **Plan Schedule Management** - Lập kế hoạch quản lý tiến độ
- **Plan Cost Management** - Lập kế hoạch quản lý chi phí
- **Plan Quality Management** - Lập kế hoạch quản lý chất lượng
- **Plan Resource Management** - Lập kế hoạch quản lý nguồn lực
- **Plan Communications Management** - Lập kế hoạch quản lý truyền thông
- **Plan Risk Management** - Lập kế hoạch quản lý rủi ro
