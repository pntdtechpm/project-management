# Test Strategy

Tài liệu chiến lược kiểm thử dự án.

## Mục tiêu

- Xác định phạm vi kiểm thử chức năng, tích hợp, hiệu năng, bảo mật và UAT.
- Thiết lập môi trường test, dữ liệu test, quy trình báo lỗi và tiêu chí pass/fail.
- Đảm bảo các module App, CMS, AI, eKYC và API được kiểm thử đầy đủ trước Go-live.
