# Project Initiation

Giai đoạn khởi động dự án (Initiating Process Group) — Vùng kiến thức Quản lý Tích hợp Dự án (Project Integration Management).

## Tài liệu

| Tài liệu | Mô tả |
|----------|-------|
| [Business Case (Luận chứng Kinh doanh)](./business-case.md) | Khung biểu mẫu, phân tích phương án, cost-benefit và kế hoạch giám sát lợi ích |
| [Project Vision (Tầm nhìn Dự án)](./project-vision.md) | Tuyên bố tầm nhìn Geoffrey Moore, phân khúc khách hàng, UVP và roadmap 3 năm |
| [Project Scope (Phạm vi Dự án cấp cao)](./project-scope.md) | Ranh giới dự án, in-scope/out-of-scope, deliverables và tiêu chí nghiệm thu cấp cao |
| [Stakeholder Register (Sổ đăng ký Các bên liên quan)](./stakeholder-register.md) | Phân loại stakeholder, Power/Interest Grid và chiến lược quản lý tương tác |
| [Stakeholder Analysis (Phân tích Các bên liên quan)](./stakeholder-analysis.md) | Ma trận mức độ tham gia, xung đột lợi ích và kế hoạch tương tác stakeholder |
| [Communication Matrix (Ma trận Truyền thông)](./communication-matrix.md) | Luồng truyền thông 5W1H, lịch họp/báo cáo và quy tắc vận hành truyền thông |
| [RACI Matrix (Ma trận Phân bổ Trách nhiệm)](./RACI.md) | Vai trò Responsible, Accountable, Consulted, Informed cho các deliverables khởi động |
| [Success Criteria (Tiêu chí Thành công)](./success-criteria.md) | Bộ KPI SMART để đánh giá thành công quản lý dự án, sản phẩm, kinh doanh và trải nghiệm |
| [Project Kickoff Checklist (Danh mục Kiểm tra Khởi động)](./project-kickoff-checklist.md) | Checklist trước, trong và sau cuộc họp kickoff để chuyển từ Initiation sang Planning |
| [Approval Workflow (Quy trình Phê duyệt)](./approval-workflow.md) | Cổng phê duyệt phase gate, phân cấp thẩm quyền DOA và quy trình kiểm soát thay đổi |
| [Project Charter theo chuẩn PMP](./project-charter.md) | Tổng quan, khung nội dung, quy trình ITTO và lưu ý quan trọng |

## Quy trình chính

- **Develop Project Charter** — Phát triển Điều lệ Dự án
- **Identify Stakeholders** — Nhận diện các bên liên quan
