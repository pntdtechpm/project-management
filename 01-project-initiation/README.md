# Project Initiation

Giai đoạn khởi động dự án (Initiating Process Group) — Vùng kiến thức Quản lý Tích hợp Dự án (Project Integration Management).

## Tài liệu

| Tài liệu | Mô tả |
|----------|-------|
| [Business Case (Luận chứng Kinh doanh)](./business-case.md) | Khung biểu mẫu, phân tích phương án, cost-benefit và kế hoạch giám sát lợi ích |
| [Project Vision (Tầm nhìn Dự án)](./project-vision.md) | Tuyên bố tầm nhìn Geoffrey Moore, phân khúc khách hàng, UVP và roadmap 3 năm |
| [Project Scope (Phạm vi Dự án cấp cao)](./project-scope.md) | Ranh giới dự án, in-scope/out-of-scope, deliverables và tiêu chí nghiệm thu cấp cao |
| [Stakeholder Register (Sổ đăng ký Các bên liên quan)](./stakeholder-register.md) | Phân loại stakeholder, Power/Interest Grid và chiến lược quản lý tương tác |
| [Project Charter theo chuẩn PMP](./project-charter.md) | Tổng quan, khung nội dung, quy trình ITTO và lưu ý quan trọng |

## Quy trình chính

- **Develop Project Charter** — Phát triển Điều lệ Dự án
- **Identify Stakeholders** — Nhận diện các bên liên quan
