# Sprint Retrospective

Tài liệu tổng kết Sprint Retrospective để cải tiến cách làm việc của team.

## Mục tiêu

- Nhìn lại cách team phối hợp trong sprint vừa qua.
- Xác định điểm tốt, vấn đề và nguyên nhân.
- Chọn một số cải tiến cụ thể cho sprint tiếp theo.

## Nội dung chính

- Điều nên tiếp tục.
- Điều cần dừng lại.
- Điều cần bắt đầu.
- Vấn đề lặp lại.
- Action cải tiến.
- Owner và deadline.

## Mẫu Retrospective

| Nhóm nội dung | Ghi nhận | Action | Owner | Deadline |
| --- | --- | --- | --- | --- |
| Continue |  |  |  | YYYY-MM-DD |
| Stop |  |  |  | YYYY-MM-DD |
| Start |  |  |  | YYYY-MM-DD |
