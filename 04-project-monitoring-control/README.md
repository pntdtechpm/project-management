# Project Monitoring & Control

Giai đoạn giám sát và kiểm soát dự án (Monitoring & Controlling Process Group) - nơi PM/PO theo dõi hiệu suất thực tế, so sánh với baseline, phát hiện sai lệch, kiểm soát thay đổi và đưa ra hành động điều chỉnh để giữ dự án đi đúng mục tiêu.

## Tài liệu

| Tài liệu | Mô tả |
| --- | --- |
| [RAID Log](./raid-log.md) | Theo dõi Risks, Assumptions, Issues và Dependencies ở cấp quản trị dự án |
| [Risk Register](./risk-register.md) | Sổ đăng ký rủi ro, xác suất, tác động, response plan và owner |
| [KPI Dashboard](./kpi-dashboard.md) | Bảng điều khiển KPI tổng hợp về tiến độ, chi phí, chất lượng, phạm vi và nguồn lực |
| [Burndown](./burndown.md) | Theo dõi khối lượng công việc còn lại theo sprint hoặc release |
| [Velocity](./velocity.md) | Theo dõi năng suất đội Agile qua story points hoặc throughput theo sprint |
| [Budget Tracking](./budget-tracking.md) | Theo dõi ngân sách, actual cost, variance, forecast và burn rate |
| [Progress Tracking](./progress-tracking.md) | Theo dõi tiến độ tổng thể, milestone, deliverable và trạng thái thực thi |
| [Scope Tracking](./scope-tracking.md) | Theo dõi phạm vi, change request, scope creep và mức độ hoàn tất deliverables |
| [Quality Metrics](./quality-metrics.md) | Theo dõi defect, test coverage, pass rate, SLA và tiêu chuẩn chất lượng |
| [Dependency Tracking](./dependency-tracking.md) | Theo dõi phụ thuộc nội bộ, bên ngoài, blocker và thời hạn xử lý |
| [Resource Tracking](./resource-tracking.md) | Theo dõi phân bổ nguồn lực, capacity, utilization và overload risk |
| [Project Health Check](./project-health-check.md) | Đánh giá sức khỏe dự án theo RAG status và các chỉ báo cảnh báo sớm |
| [Status Report](./status-report.md) | Báo cáo trạng thái định kỳ cho sponsor, PMO, stakeholder và team |

## Quy trình chính

- **Monitor and Control Project Work** - Giám sát và kiểm soát công việc dự án
- **Perform Integrated Change Control** - Kiểm soát thay đổi tích hợp
- **Validate Scope** - Nghiệm thu phạm vi
- **Control Scope** - Kiểm soát phạm vi
- **Control Schedule** - Kiểm soát tiến độ
- **Control Costs** - Kiểm soát chi phí
- **Control Quality** - Kiểm soát chất lượng
- **Control Resources** - Kiểm soát nguồn lực
- **Monitor Communications** - Giám sát truyền thông
- **Monitor Risks** - Giám sát rủi ro
- **Control Procurements** - Kiểm soát mua sắm và vendor
- **Monitor Stakeholder Engagement** - Giám sát tương tác stakeholder
